# PhysiqueOS Home Screen widget audit mockups

These are non-shipping visual studies created for the Home Screen widget architecture audit. Values are synthetic. They are not SwiftUI views and are not included in any application target.

- `home-screen-widget-v1-board.svg` — source board with six states.
- `home-screen-widget-v1-board.svg.png` — rendered review image generated from the SVG source.

The board covers:

1. small, daily-totals emphasis;
2. small, workout-launcher emphasis;
3. medium, recommended V1;
4. medium, active-workout / Resume state;
5. medium, stale/offline state;
6. medium, privacy-redacted state.

The large family is intentionally not proposed for V1: the reliable current-day contract does not justify the added density, and a large widget would drift toward reproducing Home.
