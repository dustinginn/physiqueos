# Quantitative visualization mappings

Every rendered data mark has `data-source-key` and `data-value`. The validator compares all 25 marks with the unchanged fixture; unknown, missing or changed source values fail the pass.

## Confidence

- A/B/C form: conic ring filled to exactly 68%.
- Equivalence: the geometry encodes only the score already printed in the center. Band `moderate`, movement `increased`, delta `+5` and primary reason stay exact text.

## Energy

The production W15 graph is the only existing quantitative graph. This pass transforms its form in B, which is allowed by the assignment, while preserving its comparison basis and full point set.

## Explicit non-encodings
