# Phase 1A actual Watch states

These PNGs are screenshots of the real `PhysiqueOSWatch` SwiftUI target on a 49 mm watchOS 27 simulator. They are not the Phase 0 SVG concept board.

The app was launched in Debug with `-watchFixture <state>`. The fixture injects a read-only projection into the same shipping views and is compiled out of Release; it does not provide a second structured authority or mutation path.
