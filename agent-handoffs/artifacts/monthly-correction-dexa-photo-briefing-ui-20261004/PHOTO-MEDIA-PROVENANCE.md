# Founder photo media provenance

The production architecture deliberately keeps raw Founder photo media behind authenticated, no-store resolution. Raw object identifiers and private filesystem paths are not exported into this design package.

The available safe source was the current app-rendered Progress Photos asset already stored in the repository. The harness copies pixels only and extracts:

- Back Relaxed prior reference: Jun 20;
- Back Relaxed current reference: Jun 27.

No color correction, filter, body retouching, generative fill, aspect distortion, or stock substitution was applied. The source mapping remains visible in the Photo concept. It is explicitly not asserted to be the Build 85 synthetic fixture's Aug 16 → Aug 30 underlying pair. Canonical fixture copy and the safe visual-reference media are validated as separate authorities so the package never invents a private-media association.
