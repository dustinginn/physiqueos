# Home Screen Widget V1 shipping-view renders

The seven PNGs in this directory are the Founder-requested four-tile square (`systemSmall`) renders generated by `HomeWidgetTests.testShippingViewsRenderAllRequiredStates` from the same `HomeLoggedTodayWidgetView` compiled into the existing PhysiqueOS WidgetKit extension. The optional detailed `systemLarge` renders live under `large/`. The harness supplies system-like margins and the extension's dark container color; it does not substitute a separate mockup implementation.

- `01-full-data.png` — Nutrition calories/P/C/F, partial-day active calories, and today's Weight.
- `02-no-weight.png` — today's Weight is absent and remains explicitly unlogged, never zero or a prior-day value.
- `03-active-workout.png` — the navigation action becomes Resume Workout.
- `04-stale-offline.png` — last trusted same-day values remain visible with an explicit offline/age warning.
- `05-waiting-for-today.png` — a prior-day snapshot is hidden after local midnight.
- `06-privacy-redacted.png` — daily values are redacted while the navigation action remains available.
- `07-long-training-summary.png` — square totals remain stable because Training detail is intentionally reserved for the optional large family.

No source/provenance label, including “Apple Health,” is rendered in any widget state.

On the iOS 18 deployment target, the square uses one `widgetURL` for navigation-only Start/Resume and a separate interactive refresh intent. Refresh foregrounds the app and asks the app-owned snapshot coordinator for canonical totals; the extension never authenticates to the Server or queries HealthKit.
