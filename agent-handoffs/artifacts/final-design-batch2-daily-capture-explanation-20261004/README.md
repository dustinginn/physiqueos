# Final Design Batch 2 — Daily Capture + Explanation

Founder-review package for four previously uncovered product groups:

1. Home Confidence Detail;
2. Morning Check-In;
3. manual/backdated Weight;
4. Briefing History.

Start with:

- `boards/daily-capture-explanation-primary-mobile.png` — representative dark/Mineral-Light composite covering all four groups;
- `comparison-board.html` — phone-friendly index;
- focused boards under `boards/` — complete state sets;
- `validation.json` — automated appearance/content/geometry/action proof.

The package contains 20 material surfaces, 40 full-resolution screens and 20 dark/light pairs. Every render uses a 402 pt iPhone canvas and identical dark/light geometry.

This directory contains design artifacts only. It changes no Native or Server shipping source, schema, production state, build or TestFlight artifact.
