## Visual and semantic rules

- The violet line/area is the nightly Sleep trend, not a score.
- The dashed reference is explicitly described as the personal baseline; meaning is not carried by color alone.
- Status always includes text and a marker.
- Foam remains a subordinate execution row and cannot set or rescue status.
- The accessibility label names each day/value, baseline and status.
- Confidence coupling remains `none`.
- Monthly will use weekly aggregates when designed; no 30-point nightly graph.
