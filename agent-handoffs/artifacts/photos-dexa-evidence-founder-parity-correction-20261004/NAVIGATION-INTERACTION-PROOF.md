# Navigation and interaction proof

## Photos

```text
Evidence Hub → Progress Photos
├─ Latest Photo Set module ─┐
├─ Open gallery ────────────┴→ large Photo Set sheet
├─ Read Photo Briefing → Briefing detail (published only)
└─ Uploaded Photos
   ├─ Show All / Close inline
   └─ thumbnail record / View → same large Photo Set sheet
      ├─ selected canonical pose + set date
      ├─ Previous + Current simultaneous comparison
      │  ├─ tap Previous → inspector starts Previous (1 of 2)
      │  └─ tap Current → inspector starts Current (2 of 2)
      ├─ Interpretation
      ├─ Capture Conditions
      ├─ Source History → expand / collapse inline
      └─ Previous / Next → adjacent canonical pose
```

Full-screen inspection is read-only. It does not replace the simultaneous paired composition in the set detail.

## DEXA

```text
Evidence Hub → DEXA (one scroll page)
├─ Latest Scan → optional authenticated BodySpec PDF sheet → Done
├─ Core Trends (always open, 5 interactive charts)
├─ Supplemental Metrics → Show All / Close inline
├─ Regional Tissue Lean Mass → Show All / Close inline
├─ Regional Tissue Fat Mass → Show All / Close inline
└─ Scan History → Show All / Close inline
   └─ optional View BodySpec PDF → authenticated PDF sheet → Done
```

DEXA history rows do not navigate to a scan detail.
