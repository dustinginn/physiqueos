# Structural, content and action parity proof

`validation.json` is generated from the rendered DOM and fails the build if:

- the exact Server root domain order differs;
- Recovery, Peptides or Supplements is not the next-three slice after Training;
- any requested surface is missing either appearance;
- dark/light text differs for the same surface;
- a surface title, method, field, section or canonical action from `NEXT-THREE-AUTHORITY.json` is absent;
- a rendered interactive target is below 44 pt;
- the iPhone render width differs from 402 pt;
- a forbidden invented page/action appears;
- a shipping-code-change flag is true.

The final package contains 34 full-resolution individual renders, focused domain boards, one mobile review board and one navigable comparison artifact.
