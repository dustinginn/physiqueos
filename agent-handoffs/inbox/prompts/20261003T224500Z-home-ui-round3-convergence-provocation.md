LANE B — GENUINE PROVOCATION

Round 1/2 experimental concepts were too conservative.

Changing colors while retaining the same stacked composition DOES NOT count as a new concept.

For this lane, DO NOT use the current stacked-card Home composition as the starting layout.

Produce at least FOUR genuinely different concepts.

Each must materially change at least THREE of:
- composition;
- hierarchy;
- geometry;
- grouping;
- density;
- visual flow;
- spatial relationship between Goal/Confidence/Phase/Priorities;
- interaction presentation;
- use of background/surface;
- section ordering, where product semantics permit.

Canonical information and product meaning remain fixed.

The point is not that these four must ship.
The point is to discover ideas that a conservative iteration would never expose.

B1 — DASHBOARD / MODULAR

Explore a modular dashboard rather than one vertical stack.

Possible tools:
- asymmetric modules;
- paired compact panels;
- horizontal paging for secondary goal details;
- anchored trajectory region;
- compact execution rail.

Must still be practical on an iPhone and readable.

B2 — EDITORIAL / OPEN CANVAS

Challenge the card model aggressively.

Use typography, whitespace, color fields and alignment to create hierarchy.

Cards should be rare and reserved for genuinely interactive/actionable elements.

Goal/Phase/Guardrail may read more like an editorial progression/story than stacked containers.

Do not reduce semantic content.

B3 — EXECUTION-FIRST

Explore a substantially different information hierarchy centered on "what do I need to do now?"

Morning Weight, Briefing and Today's Priorities can become the dominant execution surface, with Goal/Trajectory serving as persistent context rather than consuming the top half.

This is an experiment only; do not treat reordering as accepted product IA.

Still show all canonical Home information.

B4 — TRAJECTORY-FIRST / IMMERSIVE

Make current Goal trajectory/confidence the defining visual identity of Home.

Explore:
- large color field;
- progress geometry;
- phase path/timeline;
- compact embedded Guardrail;
- priorities layered below or over a transition surface.

Do NOT simply make the existing hero taller.

The overall composition must actually differ.
